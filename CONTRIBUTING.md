# Contributing

Add a case, a prompt, or a skill with a pull request.

## Add a case

1. Copy [cases/_template.md](cases/_template.md) to `cases/<short-name>.md`.
2. Fill in every section. Leave out nothing about what did not work.
3. Link the evidence: the REA session or findings file, the TDK `service.json`/stack, and the commands you ran.
4. Use the status labels: `Idea`, `In progress`, `Works locally`, `Verified by someone else`.
5. Add one line to the table in the README.

## Rules

- Only apps and binaries you are allowed to analyze.
- No secrets, keys, licences, proprietary assets, or personal data.
- Say which results you reproduced and which you only read about.
